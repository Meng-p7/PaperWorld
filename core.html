设置

接上你自己的模型

你只需要做一件事：粘贴自己的 API Key。后端在哪、能不能连，由页面自己确认。 不配置也能用——四幕故事会改由本地分析生成，只是讲解更朴素。

正在确认本机服务… 地址由程序自动确认。

先启动本机服务，只需一次

  1. 下载或克隆整个项目： 下载 ZIP， 或 git clone https://github.com/Meng-p7/PaperWorld.git。
  2. 解压后在项目目录双击 start-backend.bat（macOS / Linux 运行 node server/index.js），它会自动打开 http://localhost:8080。
  3. 从那个地址继续使用本站，回到这里会自动连上，只剩填 API Key。

需要 Node.js 18 或更新版本。 在线版（GitHub Pages）没有模型后端，只能使用本地分析。

模型

未配置

选择服务商后填入 API Key。Key 只发给你的后端加密保存，浏览器不留存。

高级：后端在别的域名，或后端开了访问令牌

日常使用不需要展开。只有你把后端部署到自己的域名，或设置了 PW_TOKEN 时才填。

使用与数据

怎么用
首页进入空间站选一幕，或直接上传 PDF。四幕读完后，同一页下方就是完整档案。
数据去哪
PDF 在浏览器本地解析，文件本身不上传。启用模型时，只把从 PDF 抽取的原文语句发给你自己的后端，再由后端转给模型服务；浏览器不接触 API Key。
不接模型
本地类型分析仍会生成四幕与完整档案，内容只取自原文，不会编造。
