AI Core · 唯一的模型配置入口

让模型读懂论文，
让展馆负责让人看懂

模型只在生成时工作：分析论文、规划四幕、写讲解、挑原文。展馆生成后正常浏览不再消耗 Token。 API Key 加密保存在你自己的后端，浏览器不接触密钥。

AI Core 是可选的。你只需要做一件事：填入自己的模型 API Key。 后端在哪、能不能连，都由页面自己确认——不需要你填地址。

正在确认本机服务… 地址由程序自动确认。

先启动本机服务，只需一次

  1. 下载并双击 start-backend.bat。它会自动打开 http://localhost:8080。
  2. 从那个地址继续使用本站（首页、上传、AI Core 都在同一个服务里）。
  3. 回到 AI Core，页面会自动连上，你只需要填 API Key。

没装 Node？先安装 Node.js 18 或更新版本；macOS / Linux 在项目目录运行 node server/index.js。 不想装也完全能用：上传论文照常生成四幕，只是讲解由本地分析写，不由模型写。

高级：使用自己的后端地址，或后端开了访问令牌

只有两种情况需要展开：你把后端部署在别的域名，或后端设置了 PW_TOKEN。日常使用请忽略这里。

安全与降级

  • 密钥用 AES-256-GCM 加密保存在后端，接口与日志都不回显。
  • 生产环境请设置 PW_TOKEN，否则能访问端口的人都能用你的模型额度。
  • 模型输出会逐条校验：引文必须存在于证据表，讲解出现新数值即丢弃；失败自动降级到本地分析。
  • 没有后端也能用：本地六维度分析会完成提取式策展，只是叙事更朴素。
  • 启动：双击 start-backend.bat（或 node server/index.js），它同时托管静态前端。
  • 后端地址不需要你填：同源访问时自动使用当前站点，静态托管时自动试本机 8080。

配置与密钥只存在你的后端；换前端托管不动后端，换后端不动前端。 接口与部署方式见 server/README.md。
