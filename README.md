# PaperWorld

把一篇论文，变成可以走进去的科研展览。

## 它是什么

大多数论文的问题不是难，而是没有入口。PaperWorld 做一件事：**读一篇 PDF，把它变成一个普通人愿意看完的展览。**

四幕讲清楚这篇论文为什么研究、怎么做、效果如何、价值与局限；读完想看细节，同一页往下就是完整档案——原始分厅、图表、表格、参考文献，以及可以逐页核对的原文。每一句结论都能点回论文原页看高亮。

内置一场示范展：ALOHA 低成本双臂机器人（81 条逐字核对的原文证据）。也可以上传自己的论文。

## 三个入口

| 入口 | 做什么 |
| --- | --- |
| **探索** | 进入空间站，四个舱门对应四幕；也可以从首页直接读首展 |
| **上传论文** | 放一份 PDF，在本机解析并生成属于你的展览 |
| **设置** | 填自己的模型 API Key（可选）。地址由程序自动确认，只需要粘一次 Key |

就这三个。论文展览本身不占导航：从空间站、上传完成、或首页首展进入，四幕与完整档案在同一页。

## 开始使用

需要 [Node.js 18+](https://nodejs.org/)，不需要 `npm install`。

```bash
# Windows：双击 start-backend.bat，它会自动打开浏览器
git clone https://github.com/Meng-p7/PaperWorld.git
cd PaperWorld
node server/index.js          # macOS / Linux
```

打开 `http://localhost:8080` 即可。这个地址本身就是完整站点，前端与后端同源，设置页打开就是「已连接」，只需要填 API Key。

只想看界面、不用模型：`python -m http.server 8000`，四幕会由本地分析生成。

> 不要直接双击 HTML 文件（`file://`）。浏览器会拦掉脚本模块与 PDF 解析器，页面顶部会给出提示。

## 数据与隐私

- PDF **在浏览器本地解析**，文件本身不上传。
- 启用模型时，只把从 PDF 抽取的**原文语句**发给你自己的后端，再由后端转给模型服务；浏览器不接触 API Key，Key 由后端用 AES-256-GCM 加密保存。
- 展览与原文存在本机浏览器里；清除站点数据即可删除。
- 不接模型也能用：四幕与档案由本地类型分析生成，内容只取自原文。

## 部署到自己的域名

前端可以放任何静态托管（GitHub Pages、Netlify 都行）。后端要单独跑：

```bash
PW_TOKEN=一长串随机字符 PW_SECRET=另一个只有你知道的串 node server/index.js
```

默认只绑 `127.0.0.1`、默认关闭跨域。要对外提供，必须同时设置 `PW_TOKEN`，并按需给 `PW_ALLOWED_ORIGINS=https://your.site`；前端在 `js/core/endpoint.js` 里填一行后端地址即可，访客看不到这一步。详见 [server/README.md](server/README.md)。

## 边界

- 扫描件没有 OCR，需要先自己 OCR。
- 论文类型与维度归类是启发式信号，不是语义模型。
- 首页与空间站是程序化几何，没有加载外部 3D 模型。
- 模型只负责写讲解，不能新增证据：引文与数值都会被回查，不合规就丢弃并退回本地分析。

## 目录

```
js/         前端逻辑（story 渲染、PDF 解析、策展、空间站）
server/     零依赖 Node 后端（模型代理、密钥加密）
css/        设计变量与页面样式
assets/     示范展数据、论文图与原文 PDF
docs/       技术说明（实现细节在这里，不在 README）
```
